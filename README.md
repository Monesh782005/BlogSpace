\# BlogSpace 📝



BlogSpace is a responsive frontend Blog Application developed as part of my internship project.



It allows users to register, login, create blogs, edit blogs, delete blogs, and read published blogs through a clean and responsive interface.



\## 🚀 Features



\- User Registration

\- User Login

\- Login authentication using LocalStorage

\- Protected Dashboard

\- Protected Create Blog page

\- Create and publish blogs

\- Edit existing blogs

\- Delete blogs

\- Dashboard statistics

\- Dynamic Latest Blogs section

\- Read More blog details page

\- Logout functionality

\- Responsive design for desktop and mobile devices

\- Modern glassmorphism-inspired user interface



\## 🛠️ Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- LocalStorage

\- Git

\- GitHub
